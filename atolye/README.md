# Atölye

Learn Python in 30 days in the browser: short interactive cards, live code, exercises checked by tests. Turkish and English.

- **Lesson cards:** one idea per card, code you can run, guess-the-output questions, a line-by-line visualizer. Double-click a card to see the original text.
- **Practice:** exercises from predict to write, checked by hidden tests, with hints that never give the answer away.
- **Progress:** XP, streak, spaced review, end-of-part projects. Saved in the browser, no account.

## Run

```bash
cd atolye
npm install
npm run dev
```

Requires Node.js 20.19+ or 22.12+. Python runs in the browser (Pyodide); nothing else to install.

## Contribute

Fork, make your change on a new branch, open a pull request. Tests run on every pull request; it is merged when they are green. Details for AI agents are in `AGENTS.md`.

Based on [30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python) by Asabeneh Yetayeh.
